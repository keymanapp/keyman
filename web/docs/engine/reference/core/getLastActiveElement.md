---
title: getLastActiveElement
---

## Summary

Return the last element activated before input was moved to KeymanWeb.

## Syntax

```js
keyman.getLastActiveElement();
```

### Parameters

None.

### Return Value

`Element`
:   The last element activated before KeymanWeb activated.
