--- confounds, stated rather than hidden ---

1. BUILD CONFIGURATION. The control is Release, the treatment is Debug. Not closed.

   The mechanism argues it is not material. The stall is a deliberate 5000 ms sleep
   with the modifier released 1500 ms into it. A Debug-versus-Release speed difference
   is microseconds and cannot decide whether a KEYUP lands inside a five second window.


   Closing it properly needs a --release build of this branch. That is currently
   blocked: `build.sh --release build:x86` fails in the `core` dependency with
   "Could not find vsdevcmd.bat". Recorded as unclosed rather than argued away.

2. VERSION. 19.0.276 against 19.0.277. The whole engine difference is 23 lines --
   capsstate.cpp +18, capsstate.h +1, aiTIP.cpp +3, kmhook_getmessage.cpp +6/-5 -- the
   Caps Lock resync from PR #16423. Everything else that moved between those two
   versions is insthelp and documentation.
