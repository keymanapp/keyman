---
title: What's New in Keyman 19.0 for Windows
---

Here are some of the new features we have added to Keyman 19.0 for Windows:

- Full support for Windows on ARM64 processors (#14621)
- Keyboard search pages are now available in more languages (#15510)
- Improved startup time (#14795)
- Improved stability on heavily loaded systems (#15179)
- Improvements to selection of base keyboard for mnemonic layouts (#16162)
- About [250 other fixes and changes](https://keyman.com/go/app/whatsnew/windows/19.0)
